# Contributing

Thanks for helping improve Kairo. Kairo is source-available under the Zyvor Production Licence v2.0, not open source. Please email sales@zyvor.dev before sending a change so we can agree scope.

1. Create a focused branch in your own checkout.
2. Run `gofmt -w .` on Go changes.
3. Add tests for simulator changes.
4. Run `make check` and `make test-e2e`.
5. Keep pull requests small enough to review and explain any blast-radius scoring change.

Contributions are accepted under the Zyvor Production Licence v2.0 (licensed to Zyvor AI Labs under the same terms).
